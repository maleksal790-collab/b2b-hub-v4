# B2B Hub v4 – Hybrid Investor Edition

A clean, professional investor one-pager for **B2B Hub v4** — a dual-mode B2B procurement operating system for Saudi industrial markets.

## Live URL

https://maleksal790-collab.github.io/b2b-hub-v4/

## Overview

B2B Hub v4 combines a **Storefront Marketplace** (for SMBs) and an **Enterprise RFQ Hub** (for large buyers) in one governed platform.

## Key Features

- Strong problem-solution narrative
- Clear commercial architecture (COM-001 to COM-006)
- Key metrics and financial projections
- Working contact form powered by Formspree
- Fully responsive design

## Tech Stack

- Static HTML + CSS + JavaScript
- Hosted on GitHub Pages
- Contact form via Formspree

## Deployment

1. The repository is already set up for GitHub Pages deployment.
2. Ensure GitHub Pages is enabled in repository settings:
   - Go to **Settings > Pages**
   - Select `main` branch as the source
   - Save
3. The site automatically deploys to: https://maleksal790-collab.github.io/b2b-hub-v4/
4. Future updates are automatic on every push to `main`.
